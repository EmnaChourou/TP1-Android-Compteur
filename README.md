# TP1 Android — Compteur

Ce TP consiste à créer une application Android avec Android Studio et Kotlin permettant d'incrémenter, de décrémenter et de réinitialiser un compteur. Des améliorations ont été ajoutées pour changer la couleur du compteur selon sa valeur et empêcher celui-ci de devenir négatif.

# Difficultés rencontrées

Au niveau des améliorations, j’ai d’abord ajouté un changement de couleur selon la valeur du compteur : vert pour une valeur positive, rouge pour une valeur négative et noir pour zéro. Cette fonctionnalité a été testée avec succès.

J’ai ensuite implémenté une amélioration empêchant le compteur de descendre en dessous de zéro. Ainsi, dans la version finale, les valeurs négatives ne peuvent plus être atteintes.

La condition permettant l’affichage en rouge est conservée dans le code, mais elle n’est plus visible lors de l’utilisation normale de l’application. Ces deux améliorations ont donc été réalisées et testées successivement, la limitation à zéro étant conservée dans la version finale.
